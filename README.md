# Telegram AI Reply Assistant MVP

MVP Telegram-бота «Подскажи ответ»: пользователь присылает текст или пересылает сообщение в личку боту, выбирает тон, а бот возвращает три варианта ответа для копирования. Бот не пишет в группу за пользователя.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
```

Заполните `.env`, затем запустите:

```bash
asnwero-bot
```

или:

```bash
python -m asnwero_bot
```

## Где взять ключи

- Telegram bot token: открыть [@BotFather](https://t.me/botfather), выполнить `/newbot`, скопировать token в `TELEGRAM_BOT_TOKEN`. Официальная справка: [Telegram Bot tutorial](https://core.telegram.org/bots/tutorial).
- Gemini API key: открыть [Google AI Studio](https://aistudio.google.com/app/apikey), создать ключ, вставить в `GEMINI_API_KEY`. Документация: [Gemini API keys](https://ai.google.dev/gemini-api/docs/api-key).
- OpenRouter API key: открыть [OpenRouter Keys](https://openrouter.ai/settings/keys), создать ключ, вставить в `OPENROUTER_API_KEY`. Бесплатный роутер указан как `OPENROUTER_MODEL=openrouter/free`; список бесплатных моделей: [OpenRouter free models](https://openrouter.ai/collections/free-models/).
- xAI API key: опционально, только если вы явно разрешаете платные API-запросы. Ключ берется в [xAI Console](https://console.x.ai/), документация: [xAI quickstart](https://docs.x.ai/docs/quickstart). В MVP провайдер выключен через `XAI_ENABLED=false`.

Достаточно Telegram token и хотя бы одного AI-ключа. Gemini стоит первым провайдером, OpenRouter используется как резерв. `ALLOW_PAID_MODELS=false` по умолчанию блокирует модели без `:free` и роутер `openrouter/free`.

## Команды бота

- `/start` и `/help` — краткая инструкция.
- `/cancel` — сбросить текущий сценарий.
- `/privacy` — что хранится и что отправляется AI-провайдерам.
- `/answer` в группе ответом на текстовое сообщение — бот заберет текст из replied-message и отправит меню тонов вам в личку.

## Использование в группе

1. Добавьте `@answeroilit_bot` в групповой чат.
2. Каждый пользователь, который хочет получать варианты в личку, один раз пишет боту `/start` в личном чате.
3. В группе пользователь отвечает командой `/answer` на конкретное текстовое сообщение.
4. Бот не пишет варианты в группу, а отправляет выбор тона и ответы пользователю в личку.

Privacy mode можно оставить включенным: боту не нужны права администратора и не нужно чтение всей истории группы.

## Проверка вручную

1. Напишите боту `/start` в личке.
2. Перешлите текстовое сообщение из группы или вставьте текст вручную.
3. Выберите тон: жестко, с юмором, конструктивно, научно, коротко или свой вариант.
4. Проверьте кнопки «Другой тон», «Еще варианты», «Новое сообщение».
5. Для проверки fallback временно укажите неверный `GEMINI_API_KEY`: бот должен попробовать OpenRouter, если его ключ настроен.

## Приватность и лимиты

Бот хранит минимум: Telegram user id, текущий исходный текст, опциональный контекст, выбранный тон и время создания задачи. Старые задачи удаляются по TTL. Полные тексты сообщений и секреты не пишутся в логи.

Бесплатные лимиты Gemini/OpenRouter меняются. Бот не обещает непрерывную бесплатную работу и при исчерпании всех доступных провайдеров честно отвечает, что бесплатные модели сейчас недоступны.
